# 🚲 Cycling Network Analysis - Zanica (BG), Lombardy

## Context

Regione Lombardia launched the **Bando Strade Verdi 2026**, a funding programme 
supporting the redesign of public spaces to promote active mobility — cycling 
infrastructure, pedestrian areas and school zones — with the goal of reducing 
traffic-related emissions in Lombard municipalities.

As a regular cyclist on the route to Bergamo, I have always noticed how 
fragmented cycling infrastructure tends to be in Lombardy. I chose Zanica — 
a municipality I cycle through often — as a case study to practice QGIS.

## Goal

Map the existing cycling network of Zanica and its main points of interest 
(schools, healthcare services, library, sports and cultural centres), analysing:
- current cycling infrastructure coverage
- proximity to key services — a core eligibility criterion for the grant
- missing segments or discontinuities in the network
